# Image assets

The project README and GitHub Pages landing page now use screenshots from `docs/portfolio_case/screenshots/`. This directory contains the remaining diagrams and brand source files:

| File | Purpose |
| --- | --- |
| `architecture.png` | Architecture diagram linked from `docs/index.html`. |
| `architecture.svg` | Editable vector source for the architecture diagram. |
| `logo.svg` | Canonical editable project mark. |
| `voxel_social.png` | Existing social-preview artwork, retained for possible GitHub repository settings references. |

The old multi-resolution `logos/export/` images and duplicate 512px raster variants were unused by the application, README, and Pages. They were removed from the current branch in the repository cleanup. Historical copies remain recoverable from Git history and the release source archive.

The `voxel_*` name is historical and does not indicate the current visual style.
