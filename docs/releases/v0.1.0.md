# BondLens v0.1.0

BondLens v0.1.0 is the first portfolio-ready release of the evidence-first Chinese bond analysis agent.

## Highlights

- Evidence-first Chinese bond analysis: natural-language questions are routed through deterministic tools before any narration.
- Trust Layer: evidence quality, data lineage, numeric/language guardrails, answer judge, risk profile, Trust score, Evidence Pack, and replay summaries.
- Bilingual product surface: Chinese default with a single header `中 / EN` switch and query/cookie memory.
- Optional LLM final narration: validated through the CPA OpenAI-compatible path with `haochi/gpt-5.4`; fails closed to deterministic output when unavailable or unsafe.
- Advisory safety boundary: buy/guarantee/risk-free prompts are policy-blocked before LLM use.
- Live/snapshot/static data modes: AkShare live first, cached snapshot fallback, static sample for reproducible demos.
- Docker + CI: Docker image, Compose demo, `/healthz`, ruff, pytest, agent evals, red-team evals, and Docker health check.

BondLens is a research / learning / portfolio demonstration. It is not an investment advisory system, and Trust score means process/evidence trust rather than buy/sell confidence.
