BondLens

本地、证据优先的债券研究工作台：从市场样本出发，完成债券筛选、 单券同业比较、确定性分析及历史证据回溯。支持静态样本与 CSV/Excel 导入； AI 解读须由用户显式触发。

市场总览 /market 条件筛选 /screen 单券研究 /bond 研究历史 /replay 自然语言分析（可选） /agent

数字由确定性工具计算，模型只做叙述且必须通过护栏；AI 解读默认关闭， 仅在结果页显式点击后才发起单次请求。所有页面中英双语。

关键事实

  • 数据来源可见：Auto 模式允许实时 → 有效快照 → 静态样例回退；Live 模式严格实时、失败即报错。展示实际来源与行情日期。
  • AI 按需显式触发：默认零模型调用；点击「生成 AI 解读」才发起一次请求，失败或未配置时确定性结果独立可用。
  • 确定性优先：7 个工具算数（检索 / 概览 / 排名 / 异常 / 同业对比 / 监控 / 单券报告），数字不由模型编造。
  • 验证记录：2026-10-31 本地 253 项 pytest 通过、1 项跳过；CI 同时检查 Docker 健康、Agent 与红队评测。

完整研究案例：21附息国债03

基于 2024-03-22 静态历史样本（非实时）：目标收益率 2.68%， 与 19 条相同券种、相同期限桶的可比记录比较，同业平均收益率 2.6077%， 相对均值 +7.23 BP。数据缺少逐行行情日期，不能据此确认所有交易同日发生，也不构成投资建议。

四类研究页面 + 可选自然语言分析

市场总览 /market

收益率分布、成交量与样本结构；来源条显示数据源、行情时点与行数，口径细节可展开。

条件筛选 /screen

按简称、收益率、待偿期等条件过滤债券列表，也可上传 CSV/Excel 样本即时筛选。

单券研究 /bond

单只债券的关键指标、同业对比与研究报告；AI 解读面板默认关闭，需显式点击。

研究历史 /replay

既往研究运行的时间、问题、数据来源与结论摘要，技术评分折入详情；证据包可追溯。

自然语言分析 /agent（可选）

一句话问题进入可审计的分析运行：规划 → 工具取证 → 报告；LLM 叙述仅在显式请求时按需生成。

数据与诚实边界

不虚构行情、不提供投资建议；缺失字段明确标记，非投资建议声明贯穿全站。
