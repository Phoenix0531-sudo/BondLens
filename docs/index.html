BondLens

面向中国债券市场的专业研究工作台：市场总览、条件筛选、单券研究、研究历史， 外加可选的自然语言分析入口。数据来源与行情日期全程可见，利率债优先， 支持公开行情与本地 CSV/Excel 样例。

市场总览 /market 条件筛选 /screen 单券研究 /bond 研究历史 /replay 自然语言分析（可选） /agent

数字由确定性工具计算，模型只做叙述且必须通过护栏；AI 解读默认关闭， 仅在结果页显式点击后才发起单次请求。所有页面中英双语。

关键事实

  • 数据来源可见：AkShare 实时 → 快照 → 本地样例逐级回退，或上传 CSV/Excel；每次运行显示来源与行情日期。
  • AI 按需显式触发：默认零模型调用；点击「生成 AI 解读」才发起一次请求，失败或未配置时确定性结果独立可用。
  • 确定性优先：7 个工具算数（检索 / 概览 / 排名 / 异常 / 同业对比 / 监控 / 单券报告），数字不由模型编造。
  • 质量基线：Python 3.12 · 212 项 pytest 通过（1 项跳过）· 守护栏 + 评审 + 证据包 + 回放。
本页是 GitHub Pages 静态介绍页，不提供在线交互服务。 完整工作台请按 README 本地运行：python app.py，或 docker compose up --build。

以下为当前版本真实页面截图（本地样例数据，非实时行情）。交互应用需本地运行后访问。

四类研究页面 + 可选自然语言分析

市场总览 /market

收益率分布、成交量与样本结构；来源条显示数据源、行情时点与行数，口径细节可展开。

条件筛选 /screen

按简称、收益率、待偿期等条件过滤债券列表，也可上传 CSV/Excel 样本即时筛选。

单券研究 /bond

单只债券的关键指标、同业对比与研究报告；AI 解读面板默认关闭，需显式点击。

研究历史 /replay

既往研究运行的时间、问题、数据来源与结论摘要，技术评分折入详情；证据包可追溯。

自然语言分析 /agent（可选）

一句话问题进入可审计的分析运行：规划 → 工具取证 → 报告；LLM 叙述仅在显式请求时按需生成。

数据与诚实边界

工程与运行

本地运行

Python 3.12 + Flask/Jinja + pandas，python app.py 即可离线样例分析；Docker Compose 单容器部署，健康检查 /healthz。

质量与验证

212 项 pytest 通过（1 项跳过）、agent 与红队评测脚本、CI 含 Docker 构建健康检查；同步与 SSE 共用同一条分析管线。
